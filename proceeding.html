Useful Guidelines in Case of Access/Authentication Problems

  • Sometimes individual computer settings (firewall, etc.) prevent correct forwarding and recognition on SpringerLink. Please try from your personal computer instead of your professional one, or use a different internet browser than before.
  • Please be informed that access problems can occur if you have installed anti-virus software (regardless of which one, e.g. NORTON, AVIRA, KASPERSKY, SYMANTEC, etc.) on your own computer and it blocks the communication. In this case, please disable the HTTP referrer blocker so that the conference website (https://2026.flins.cc) and SpringerLink (https://link.springer.com) can communicate properly.
  • Please be informed that IP recognition always takes priority on SpringerLink and suppresses any other logins. If you try to test access within a corporate network (university/institution/clinic, etc.), please try it from outside instead (via your private computer, laptop, netbook, smartphone, etc.).
  • It is also helpful to clear your cache and delete stored cookies.
